Qualidade observada

Dicionário dos indicadores

C: líder venceu. D: líder perdeu. E: atletas empataram nos golpes significativos conectados.

Concordância = 100 × C / (C + D). Divergência = 100 × D / (C + D). Cobertura classificável = 100 × (C + D) / (C + D + E). Denominador zero = não calculável.

H1 compara a concordância global com 50%. H2 subtrai a taxa das divididas da taxa das unânimes. Sensibilidade aos empates: 100 × C / N até 100 × (C + E) / N. São limites de atribuição dos empates, não intervalos de confiança.
